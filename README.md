# mi-portafolio
# 📄 Hoja de Vida - Emmanuel Palacios

Este proyecto corresponde a mi portafolio personal en formato de **hoja de vida**, desarrollado con **HTML semántico** y **CSS modular**.  
Hace parte de la práctica solicitada en clase, cumpliendo con los criterios de commits semánticos, ramas de desarrollo y despliegue en **GitHub Pages**.

---

## 🚀 Tecnologías utilizadas
- HTML5 (etiquetas semánticas: `<header>`, `<main>`, `<section>`, `<footer>`)
- CSS3 (variables, modularización básica, estilos progresivos)
- Git & GitHub (control de versiones)
- GitHub Pages (para el despliegue)

## 📝 Proceso de desarrollo
Durante el proyecto se aplicaron **commits semánticos** siguiendo buenas prácticas:

- `feat:` agregar nuevas secciones en HTML (información personal, perfil, experiencia, enlaces, observaciones)
- `style:` aplicar estilos progresivos (base, header/footer, secciones, tabla, listas, formulario)
- `docs:` actualizar documentación en este README

### Ejemplos de commits realizados:
1. `feat: crear estructura inicial del proyecto (HTML, CSS, README)`
2. `feat: agregar sección de información personal con tabla`
3. `style: configurar estilos base (reset, variables y fondo general)`
4. `style: aplicar estilos al header y footer`
5. `style: dar formato a las secciones (fondo, bordes y espaciado)`
6. `docs: agregar README con descripción del proyecto`
